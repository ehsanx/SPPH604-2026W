# Milestone briefs — M0 to M4

The assignment text students read on Canvas. **These pages describe the task only.** Weight,
deadline, week, and policy live in the syllabus and are deliberately not repeated here, so
the briefs can be reused from year to year without going stale.

| | Brief | Shape |
|---|---|---|
| M0 | [Feasibility gate](M0_assignment.md) | Memo locking the paper |
| M1 | [Replication and interrogation](M1_assignment.md) | Deck + code zip |
| M2 | [Critique of another group's M1](M2_assignment.md) | Deck |
| M3 | [Live oral defense](M3_assignment.md) | Live, no submission |
| M4 | [Reanalysis letter + repo](M4_assignment.md) | Letter + code zip |

## Reading them

Each brief is the assignment itself: what the milestone asks for, what you hand in, and
what it is judged on. Read one next to the matching worked example in
[`../examples/`](../examples/), which shows the standard on the demonstration paper.

The same text is posted on Canvas, which is where you submit. Canvas supplies the
assignment title itself, so the version there opens at the first section instead of
repeating the heading, and task-list boxes show as `☐` rather than as boxes you can
tick. Nothing else differs between the two; if you ever find that it does, say so and
the copy here will be corrected.

Points and due dates come from the syllabus, which is why they are not repeated here.

The **M4 bonus** cannot be encoded in a weighted Canvas scheme — it is a manual adjustment
at final-grade entry, capped as the syllabus specifies.

The **Grade Re-weighting Plan** is a Canvas **inbox message** to the instructor, not an
assignment.
